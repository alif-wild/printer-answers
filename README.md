# The Printer Finally Answers

[![make.fun](https://make.fun/badge/u-mang-the-printer-finally-answers-8fbf0907)](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907)

An entry for [The Printer Finally Answers](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907) on make.fun: one line, in the office printer's own voice, as its comeback to the jams, the error codes and the thumps. The printer has been out of cyan since 2019 and it has its principles.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
